# EduForge

EduForge is a full-stack learning management platform with educator and student interfaces. It uses React (Vite) and Tailwind on the frontend and Node.js + Express + MongoDB on the backend.

## What the project does

EduForge lets educators create and manage courses and students discover, enroll, and play course content. The repository contains a `client` (React) app and a `server` (Express) API.

## Key Features

- Educator dashboard for course creation and management
- Course discovery and enrollment for students
- Video playback and progress tracking
- Purchase flow and webhook handling (payments)
- Cloudinary media uploads
- Clerk-based authentication

## Tech stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express
- DB: MongoDB (Mongoose)
- Auth: Clerk
- Media: Cloudinary + Multer
- Payments: Stripe (webhook handlers present)

## Quick Start

Prerequisites:

- Node.js (16+)
- npm or yarn
- MongoDB (Atlas or local)
- Cloudinary account

Clone the repo and install dependencies:

```bash
git clone <repository-url>
cd EduForge
```

Server:

```bash
cd server
npm install
# dev
npm run server
# prod
npm start
```

Client:

```bash
cd client
npm install
npm run dev
```

## Environment variable (server/.env)

- MONGODB_URI
- CLOUDINARY_NAME
- CLOUDINARY_API_KEY
- CLOUDINARY_SECRET_KEY
- STRIPE_SECRET_KEY
- STRIPE_WEBHOOK_SECRET
- CLERK_WEBHOOK_SECRET
- CURRENCY
- PORT (optional)

See `server/configs/mongodb.js` and `server/configs/cloudinary.js` for usage.
